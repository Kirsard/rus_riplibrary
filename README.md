# Перевод библиотек модулей TheRipper93
Данный перевод выполнен для домашнего пользования. Возможны ошибки или неправильные формулировки, по мере выявления они будут устраняться. 

Практически все модули TheRipper93 уже имеют переводы на многие языки, в том числе на русский. Однако, некоторые из них завязаны на работе с библиотеками, которые не переводятся через lang файлы. Из-за этого переведенным остается только интерфейс, не затрагивая содержимое. 
Данный модуль исправляет эту проблему, переводя библиотеки следующих модулей:

- Maxwell's Manual of Malicious Maladies
- Potion Crafting & Gathering

Скорее всего есть более удобные способы перевода, или быть может, уже существующие переводы библиотек, но я ничего из этого не нашел, и поэтому принял решение сделать собственное решение.
